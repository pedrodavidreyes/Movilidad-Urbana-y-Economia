# 🚦 Movilidad Urbana y Economía en Latinoamérica

## 📌 Descripción
Análisis exploratorio de datos que evalúa la relación entre la congestión 
vehicular y la productividad económica (PIB per cápita) en 15 ciudades 
de 7 países latinoamericanos durante 2024.

## 🎯 Objetivo
Identificar ciudades prioritarias para inversión en infraestructura de 
transporte, cruzando datos de movilidad (TomTom Traffic Index) con 
indicadores económicos (OECD Cities).

## 🛠️ Herramientas y tecnologías
- Python (pandas, numpy, matplotlib, seaborn)
- Jupyter Notebook / Google Colab
- Limpieza y transformación de datos
- Visualización exploratoria

## 📊 Principales hallazgos
- Ciudad de México presenta el mayor índice de congestión (jams_delay: 2,833)
- Montevideo tiene el mayor PIB per cápita con el menor tráfico
- No existe una correlación directa entre congestión y nivel económico
- Se recomienda inversión prioritaria en Bogotá y Lima
